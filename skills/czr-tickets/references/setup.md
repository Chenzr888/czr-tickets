# 接入工单

目标：十分钟内让用户的项目能收单、客户能看进度。对方可能完全不懂技术，全程你来做，只在下面三个问题上问他。

## 1. 先看项目（不问用户）

- 有没有 git？没有就问一句"要不要我帮你开启版本记录，这样每次改动都能撤回"——工单流程需要它（规矩 8）。
- 是网站吗？用什么写的（看 package.json、目录结构）？有没有登录？平时怎么启动？
- 根目录有没有 `.gitignore`、`.env`。

## 2. 一次问完四个问题（每个都给推荐选项，用户可以只回"都按推荐"）

1. **单子从哪来？**
   - 网站上加一个反馈按钮（有网站就推荐这个）
   - 先不加按钮，我自己在对话里记（比如"记一张单子：首页加载很慢"）
2. **有新单子 / 修好了，通知谁？** 飞书、企业微信、钉钉、Slack、Discord 的群机器人地址；或者不通知（推荐先不通知，以后随时加）。
3. **改进单谁来批复？** 默认就是你本人，在对话里跟我说"批复 0003"就行。
4. **什么时候处理？** 你说一声再处理（推荐先这样）／每隔一段时间自动看一眼／来单就自动处理。选了后两种，按 `triggers.md` 配好，并问清他用的是哪个 AI。

## 3. 建好单子文件夹

- 建 `tickets/`，放一个 `tickets/说明.md`，内容就三句话：单子在这里、怎么批复、怎么开始处理（用用户能看懂的话）。
- 把 `tickets/` 加进 `.gitignore`：单子里有客户原话和联系方式，不该跟代码一起传到网上；切换分支时单子也不会跟着变。
- 选了通知：把地址写进 `.env` 的 `TICKETS_WEBHOOK=`，确认 `.env` 在 `.gitignore` 里；然后用 `notify.mjs "工单通知测试"` 发一条，让用户确认群里收到了。

## 4. 网站加反馈按钮（选了才做）

参考做法在本技能 `assets/widget.js`（按钮和弹窗）和 `scripts/server.mjs` + `scripts/tickets-lib.mjs`（接口和单子读写）。**不要原样硬塞**，按对方项目原有的写法接进去：

- **接口**：在对方的后端加两个接口，行为照 `server.mjs`：
  - `POST /api/tickets`：收 `{type, text, contact}`，建单子，返回 `{id, key}`
  - `POST /api/tickets/mine`：收 `{keys}`，只返回这些钥匙对应的单子，且只含客户可见字段（`publicView`）
  - 后端是 Node：把 `tickets-lib.mjs` 复制进项目，直接用；别的语言就照它的格式重写一份读写（格式见 ticket-format.md），保证命令行工具还能读。
  - 有登录：单子归到登录用户（`owner: user:<编号>`），"我的工单"按登录用户查，不用钥匙。
  - 没登录：提交后把返回的 key 存在浏览器里，查进度时带上。
  - 加一个简单限流：同一个人/同一个地址一天最多 20 张。
- **按钮和弹窗**：交互必须保持一致——点开先选「查看工单进度 / 提交工单」；提交分「遇到问题 / 改进建议」；进度页有五格进度条、处理记录、给客户的说明。
  - 纯 HTML 网站：复制 `widget.js` 进项目，页面里加一行 `<script src="/tickets-widget.js" data-api="/api/tickets" defer></script>`。
  - React / Vue 等框架：用项目自己的组件和样式重写成一个组件，配色、圆角、字体跟网站一致。
  - 网站已有"反馈""帮助"入口：不加悬浮按钮（`data-button="none"`），让原入口打开这个弹窗。
- **安全**：客户写的内容只能进单子正文，不能影响头部（`tickets-lib.mjs` 已处理，自己重写时要照做）；进度接口绝不返回内部建议、联系方式、别人的单子。

## 5. 自己试一遍

1. 启动网站，用按钮提一张测试单（"测试：这是一张测试工单"），确认 `tickets/` 里出现了文件。
2. 打开"查看工单进度"，能看到这张单子在「收到」。
3. `stage <编号> 分析中 "测试进度"`，刷新进度页，进度条往前走了一格。
4. 删掉这张测试单。

做不到的步骤如实告诉用户，不要说"应该可以"。

## 6. 收尾，告诉用户三件事

- 客户怎么提单、怎么看进度（一句话）
- 你怎么看单子、怎么批复（"看看工单""批复 0003"）
- 怎么让 AI 开始干活（"处理工单"，或者他选的定时 / 自动方式怎么开、怎么停）
