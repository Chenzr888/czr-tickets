# AI 工单

先读 `references/rules.md`，那几条规矩任何时候都不能破。然后按用户的话选一个：

| 用户在说 | 读 |
|---|---|
| 接入 / 安装 / 加反馈按钮 / 第一次用 | `references/setup.md` |
| 处理工单 / 开始干活 / 看看有没有新单子 | `references/run.md` |
| 批复 / 不做 / 上线了 / 看某张单子 | `references/manage.md` |
| 定时处理 / 来单自动处理 / 接进 GitHub、定时任务 | `references/triggers.md` |

单子的格式见 `references/ticket-format.md`。读写单子一律用 `scripts/tickets.mjs`，不要手改格式（只读可以直接打开文件看）。

本技能目录下的脚本用绝对路径调用，例如 `node <本技能目录>/scripts/tickets.mjs list`，在用户项目根目录执行。

跟用户说话用大白话：不贴代码、不报命令，说清楚"哪里出了问题、现在到哪一步、要你做什么"。
